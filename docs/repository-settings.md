# リポジトリの表示の設定（管理者向け）

[README に戻る](../README.md)

GitHub のリポジトリの説明文・Topics・共有用の画像（Social preview）は、リポジトリの設定です。ファイルをマージしただけでは反映されません。リポジトリの管理者が GitHub の画面で設定します。

## 説明文（Description）

リポジトリのトップページの右側「About」の歯車から入力します。

```text
Reusable Agent Skills for applying five original UI designs to web apps (Claude Code / Codex).
```

## Topics

同じ「About」の画面の「Topics」に入力します（小文字・ハイフン区切り）。

```text
agent-skills
ui-design
design-system
claude-code
codex
web-ui
```

## 共有用の画像（Social preview）

「Settings」→「General」→「Social preview」の「Edit」→「Upload an image…」で、[images/social-preview.png](images/social-preview.png)（1280×640px）を選びます。リンクを共有したときのカード（SNS・チャットなど）に表示されます。

![共有用の画像：design-skills の題名と、糸の交点・折本・二色刷り・汀線・標示盤の5つの適用見本の画面を並べたもの](images/social-preview.png)

画像の5つの画面は、README のプレビュー画像（`docs/images/<Skill 名>-preview.webp`）と同じ適用見本から作りました。
